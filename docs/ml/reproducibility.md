# Reproducibility and artifacts

## Environment and source data

Mission 02 was run with Python 3.11.8, NumPy 2.3.5, pandas 3.0.5, scikit-learn 1.9.1, and joblib 1.6.0 in the isolated .venv-isolated environment. requirements-mission02.lock records the resolved dependency set. The real CSV is verified against SHA-256 76274b691b16a6c49d3f159c883398e03ccd6d1ee12d9d8ee38f4b4b98551a89 before experiment preparation.

The split manifest records the dataset hash, schema, seed, timestamp boundaries, partition counts, duplicate audit, software versions, and expanding-fold boundaries. Row positions are regenerated from the verified source; no row-level split file is committed.

## Re-run commands

From the project root in PowerShell:

    powershell -NoProfile -ExecutionPolicy Bypass -File scripts\train-models.ps1 -PythonPath .venv-isolated\Scripts\python.exe
    powershell -NoProfile -ExecutionPolicy Bypass -File scripts\evaluate-models.ps1 -PythonPath .venv-isolated\Scripts\python.exe
    powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-model-artifacts.ps1 -PythonPath .venv-isolated\Scripts\python.exe

Training appends a registry record and creates a versioned local artifact. The final evaluation will score the final test partition; do not run it to make development decisions. For routine checks and an opt-in train/validation integration smoke test, see the README.

## Saved outputs

Aggregate results, reports, figures, model comparison, threshold tables, the split manifest, artifact manifests, and the append-only experiment registry are committed under reports/ml/. Row-level predictions, raw data, virtual environments, and joblib files are excluded from Git. The latest supervised artifact and the separate Isolation Forest artifact are stored locally under data/models/; manifests contain their paths, hashes, byte sizes, schema, and library versions.

The artifact loader checks checksum when supplied, schema, threshold, and scikit-learn version. Joblib deserialization can execute code, so only load trusted artifacts generated by this project; the inference API does not accept user-supplied artifact paths.

## Repeat-evaluation audit

The registry has two deterministic runs for this completion. The first run had valid supervised results but omitted the Isolation Forest artifact manifest. After fixing that persistence defect, the workflow was rerun so both model artifacts could be verified. The final test metrics were identical across the two entries, but the same frozen final-test partition was therefore scored twice. This audit caveat is disclosed in leakage-prevention.md. Future experiments must treat the final period as consumed and use new later data for independent evaluation.

Reproducibility does not imply external validity. The dataset covers a short historical interval; the selected model has not been tested against later months, other populations, changing prevalence, entity-level leakage, or a production stream.
